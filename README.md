## 1. 研究背景与组内现状

### 组内情况

目前课题组内有工程人员正在开发一套 **“SOP + MCP + 无人车/机器人”** 的系统架构：
- **核心机制**：将无人车或机器人的底层功能模块进行 **MCP（Model Context Protocol）化封装**，并通过心跳机制（Heartbeat）提供实时在线的访问入口，使大模型能够动态感知当前硬件系统具备的能力集。
- **阶段目标**：
  - *初期目标*：通过单句自然语言指令，让大模型自动组合已有功能模块，完成避障、寻迹等基础任务。
  - *远期愿景*：依托 SOP（标准作业程序/行为树等）与 MCP 协议，实现无人车在复杂场景下的任务泛化。

### 个人目标

注意，上面是我们组里开发 SOP + MCP的阶段目标，不是我的个人目标。
我的个人目标只是找到一个可行的、有一定意义(要求不是特别高)的研究方向，然后发出论文保证自己可以毕业。

| 约束维度 | 具体情况说明 | 对研究选型的硬性要求 |

| **场景与硬件载体** | 课题组主攻**越野环境无人车（Off-road UGV）**，与常规室内机械臂/操作任务差异显著。但越野底层的可通行性估计等工程极其繁琐。 | **当前不强行绑定越野场景**，优先在通用移动机器人/无人车室内外仿真中把核心机制做通；若所选方向未来能平滑扩展至越野场景（如地形自适应参数配置等）则为加分项。 |
